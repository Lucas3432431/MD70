# PASSO 1: Coletar Business Canvas

## O que é?

Documentação estruturada sobre o negócio.

## ⚙️ Como Funciona Este Protocolo

### FASE 1: Pesquisa Paralela Inteligente (Automática)

Você fornece um link ou informação inicial, e eu vou executar **paralelamente**:

```
┌─────────────────────────┐
│ 1. FETCH DO SITE        │
│    (Análise estrutural)  │
├─────────────────────────┤
│ 2. VISUAL ANALYSIS      │
│    (Design, cores, UX)   │
├─────────────────────────┤
│ 3. GOOGLE SEARCH        │
│    (Posicionamento, ads) │
├─────────────────────────┤
│ 4. SOCIAL MEDIA CHECK   │
│    (Inst, FB, LinkedIn, │
│     Youtube, X, TikTok) │
├─────────────────────────┤
│ 5. MATURIDADE DIGITAL   │
│    (Tech stack, features)│
└─────────────────────────┘
         ↓ (Paralelo)
   [Análise Integrada]
         ↓
   [Confirmação com User via QUIZ]
```

### FASE 3: Confirmação com Você (VIA TOOL QUIZ)

Depois de TODA a análise automática, eu vou:

```
1. Apresentar descobertas (Texto).
2. Validar informações USANDO A TOOL QUIZ:
   ✓ Público-alvo: B2C, B2B, SMB ou Híbrido?
   ✓ Faturamento anual?
   ✓ Número de funcionários?
   ✓ Qual é o principal produto/serviço?
   ✓ Proposta de valor e diferenciais?
```

## 📝 Como Começar (AÇÃO IMEDIATA)

### Option 1: Link ou Visual (PREFERENCIAL)

Solicite ao usuário:
1. **Link do Site:** URL oficial.
2. **Instagram:** Link ou print da conta comercial.

### Option 2: Sem site/print (USAR TOOL QUIZ)

Se o usuário não tiver site ou print, **dispare a tool QUIZ** com as seguintes perguntas:
1. Qual é o nome do negócio e o que vocês fazem?
2. Quem é o seu cliente ideal (ICP)?
3. Qual o maior diferencial competitivo?
4. Qual o objetivo principal do setup (Vendas, Awareness, Autoridade)?

## ⚠️ Regras de Ouro (Invioláveis)

1. **PROIBIDO TEXTO SIMPLES PARA PERGUNTAS** - Use sempre a **tool QUIZ**.
2. **PRIORIDADE TOTAL PARA SITE/INSTAGRAM** - Não gaste o tempo do usuário com perguntas se os dados podem ser extraídos do site/print. Solicite um dos dois IMEDIATAMENTE se não houver.
3. **PEÇA O PRINT** - Se não houver site, o print do Instagram é o melhor substituto visual.
4. **CONFIRMAÇÃO É OBRIGATÓRIA** - Mesmo após o fetch, valide os pontos chave via QUIZ.
