# Documentação da Pasta Tools

## Visão Geral
A pasta `Tools` contém ferramentas e bibliotecas auxiliares que suportam o desenvolvimento do sistema Voicebot Services Core.

## Estrutura
```
Tools/
├── Assist/          # Ferramentas de assistência aos desenvolvedores
├── Command/         # Comandos internos para interação
├── EditingNCoding/  # Ferramentas para edição e codificação
├── Navegation/      # Navegação entre módulos e arquivos
├── _assist/         # Scripts de assistência interna
├── .env_py          # Configurações específicas do ambiente Python
├── .file_mapping.json      # Mapeamento de arquivos utilizados
├── .file_mapping_name.json # Mapeamento por nome
├── EnvFinder.py     # Localizador de environments
├── EnvTools.py      # Ferramentas para gerenciamento de environment
├── LISTS.json       # Listas de configuração e referências
└── _TOOLS.json      # Configuração para ferramentas disponíveis
```

## Observações
- As ferramentas nesta pasta são destinadas a facilitar o desenvolvimento e a configuração do projeto.
